Supported Excel Formats:
  • Subscription Sheet: Columns "Player", "Member", "Subs Due", "Subs Outstanding", "Cash", "Credit", "Bank"
  • Matches Sheet: Columns "Player" and "Member" (Yes/No)
  • Memberships Sheet: Columns "Name" and "Membership" with fees
  • Simple List: Column "Name" with player names
  • Nets Sheet: Column "Name" with player names
Important Notes:
  • For Balance Sheets: Existing payment records will be updated
  • For other formats: Players with existing names will be skipped
  • All imported players will be marked as members by default
  • Maximum file size: 16MB
